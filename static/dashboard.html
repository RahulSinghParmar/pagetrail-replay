Website session versus text-only exports

Website session (.html): captured visual documents, accessible embedded course frames, styles, images and fonts in one file. Open directly in Edge/Chrome. Browse recorded states with Previous/Next, the selector, captured links and recorded button transitions. Original site scripts are not executed; quizzes, server-only actions, unvisited destinations and audio/video are not recreated.

Captured text (.md) / text-only reading (.html): secondary formats for notes, not copies of the webpage. New visual recordings extract text from every saved frame/state; older recordings may contain only the outer page.

WACZ: resource archive for the separate replay reader. Older recordings are preserved, but do not have visual states retroactively added. For one-file website HTML, record a new session with 0.1.2; only material visited while recording is included. Pause briefly after opening each section so it can be saved.

Check the visual-state/document counts below before exporting. Coverage details inside HTML list missing resource references. A large file alone does not prove a complete course. Preview limits: 500 visual states, 100 MB visual storage and 100 MB per export. Keep this library tab open until download completion.

Saved content and URLs can contain confidential data. Keep exports local and review before sharing or importing into another service. Export failures never delete the recording.
