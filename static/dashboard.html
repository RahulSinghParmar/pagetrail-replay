Formats and limits

Website HTML: one file with captured states, frames, styling and images. Original scripts, server actions, quizzes, audio/video and unvisited content are not recreated. Read the file's coverage report. Markdown / text-only HTML: captured source text, not validated study notes. WACZ: resource replay in the separately bundled local reader. Coverage JSON: observed request outcomes; source queries/credentials are omitted, but paths can still be private. No report is uploaded.

Older recordings retain text/WACZ exports and show unknown network coverage. New network captures are limited to 20 MB per response, 100 MB referenced response bytes per session, and 10,000 tracked requests. These are archive limits, not a limit on the website's own downloading or guaranteed peak memory. Visual limits remain 500 states and 100 MB referenced resources/export. Keep the library open while saving. Cancel or a failed export never deletes your recording.

Using the portable learning ZIP

Unzip once. Open index.html for a self-contained reading copy, or import the two descriptively named Markdown files into your notes app and keep the assets folder alongside them. AFFiNE's Markdown-with-media import preserves saved PNG/SVG images, headings, lists, tables and code, but its tested web importer does not preserve custom section anchors or automatically attach linked PDFs. PageTrail therefore uses explicit section references instead of false navigation links; add PDFs from assets manually if needed. README.txt explains the package and does not create an extra Markdown note. manifest.json records sources, capture times, file hashes and gaps. This format does not recreate the original interactive website; keep WACZ for replay. No missing resources are fetched and no notes app is contacted.
